Graph indexes and graph queries in Strata

Strata keeps a table's text, structured fields and vectors in one file and queries them with SQL. Rows can now link to other rows. A traversal, a shortest path or personalized PageRank runs in the same statement as BM25, filters and vector search, and can start from any of them. This page covers how edges are stored and resolved, the SQL, the planner's part, speed against SQLite and an in-memory graph, and whether the graph helps search when a vector search is the way into it. It does: on arXiv, the papers cited by a new paper's two nearest neighbours find twice as many of its references as vector search alone. A graph built from the vectors themselves does not help.

Reproduce

cd strata && cargo test --release                         # graph unit tests and tests/graph.rs among them
# ogbn-arxiv (Open Graph Benchmark) and the papers' titles and abstracts
curl -O https://snap.stanford.edu/ogb/data/nodeproppred/arxiv.zip          # into /home/user/data/graph/arxiv, unzipped into raw/
curl -O https://snap.stanford.edu/ogb/data/misc/ogbn_arxiv/titleabs.tsv.gz
python3 -I scripts/prepare_arxiv.py /home/user/data/graph/arxiv
engram-bench embed --input /home/user/data/graph/arxiv/arxiv.jsonl --out /home/user/data/graph/arxiv/arxiv.f32
cargo build --release --features baselines --bin strata-graph-bench
target/release/strata-graph-bench load                      # holds out 1,000 papers of OGB's test split
target/release/strata-graph-bench latency --sqlite /home/user/data/graph/arxiv/edges.sqlite
target/release/strata-graph-bench quality --seeds 1,2,3,5,10,20,50
python3 scripts/graph_quality_stats.py results/graph/quality_arxiv.rows.jsonl.gz --out results/graph/quality_stats.json
target/release/strata-graph-bench synthetic --nodes 1000000 --sqlite /home/user/data/graph/synthetic.sqlite
python3 scripts/build_graph_report.py                       # this page
