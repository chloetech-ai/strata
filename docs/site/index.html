Every feature
One query

Four indexes, one statement

Other stacks join a database, a search engine, a vector store and a recommender in application code. In ChloeDB it is one query, and the planner decides how to run each part.

  • Full text finds "wireles controller" despite the typo
  • Columns keep the price range and two items per brand
  • Vectors add what is close in meaning
  • Graph adds what this user's recent purchases lead to
search.sql
SELECT id, title, price, score() FROM products
WHERE MATCH(title, 'wireles~ controller')
  AND price BETWEEN 20 AND 60 AND in_stock = TRUE
ORDER BY rrf(
    bm25(title, 'wireless controller'),
    similarity(emb, :query_vector),
    ppr(bought_with, (SELECT item FROM reviews
        WHERE usr = :user ORDER BY ts DESC LIMIT 5)))
  DESC MAX 2 PER brand LIMIT 10;

Laptop to cloud

Start with a file. Grow to a cluster. Keep your queries.

The same schema, the same SQL and the same file format at every step.

In your app

A file, like SQLite

Open it from Python, JavaScript, Java or Rust. No server to run.

db = chloedb.open("shop.chloedb")
One server

HTTP, gRPC and a console

Serve the same file, with API keys and replicas when you need them.

chloedb-server --db shop.chloedb
In the cloud

Shards on Kubernetes

An operator that scales, upgrades and fails over a sharded cluster.

kubectl apply -f operator.yaml -f cluster.yaml

Try a query

Every example runs against the same shop: products, reviews and users.

SELECT id, title, price, score() FROM products
WHERE MATCH(title, 'controler~ OR gamepad', synonyms => 1)
  AND price BETWEEN 20 AND 60 AND in_stock
ORDER BY bm25(title, 'controller gamepad') DESC LIMIT 10;
SELECT id, title, score() FROM products WHERE in_stock
ORDER BY rrf(bm25(title, :q), similarity(emb, :v)) DESC LIMIT 10;
SELECT id, title, brand FROM products WHERE in_stock
ORDER BY similarity(emb, encode('next',
  (SELECT item, ts FROM reviews WHERE usr = :u ORDER BY ts DESC LIMIT 200)))
DESC MAX 2 PER brand LIMIT 10;
SELECT id, title, hops() FROM products
WHERE REACHABLE(bought_with, 'B07XYZ', hops => 2, dir => 'both') AND in_stock
ORDER BY hops(), id LIMIT 20;
SELECT p.brand, COUNT(*) AS reviews, AVG(r.stars) AS stars
FROM reviews r JOIN products p ON r.item = p.id
WHERE r.ts >= '2026-01-01'
GROUP BY p.brand ORDER BY reviews DESC LIMIT 10;

Start with a file in your app

Install the Python package, a prebuilt wheel for Linux and macOS (Python 3.10 or later), then open a file and query it. Nothing to compile.

pip install chloedb
python3 - <<'EOF'
import chloedb
db = chloedb.open("shop.chloedb", schema={"table": "products", "key": "id",  # a new file needs a schema
    "fields": [{"name": "id", "type": "keyword"}, {"name": "title", "type": "text"}]})
db.upsert({"id": "p1", "title": "Trail running shoes"})
print(db.search("shoes").dicts())
EOF

Or run the server, prebuilt, with SQL over HTTP and the command center in your browser:

curl -fsSL https://chloetech-ai.github.io/chloedb/install.sh | sh
QuickstartPython guide

On Windows (outside WSL 2) or Alpine there is no wheel yet: build the package from source, which needs Rust and a C compiler.
