# ChloeDB logo

The low-poly Australian shepherd with a red bandana, traced from the original
artwork into polygons, and the wordmark set in Inter ExtraBold, as outlines
(no font is needed to show any of these files).

| file | use it for |
|---|---|
| `chloedb-logo.svg`, `chloedb-logo-1024.png` | the full logo on its navy square, as drawn |
| `chloedb-logo-on-dark.svg`, `chloedb-logo-on-dark-512.png` | the logo with a transparent background, on a dark background ("Chloe" in white) |
| `chloedb-logo-on-light.svg`, `chloedb-logo-on-light-512.png` | the logo with a transparent background, on a light background ("Chloe" in navy, a navy edge around the dog so its white face holds against white) |
| `chloedb-wordmark-on-dark.svg`, `chloedb-wordmark-on-light.svg` | the dog and the name on one line, for a header or a README |
| `chloedb-mark.svg` | the dog alone, transparent, on a dark background (the website's and command center's dark theme) |
| `chloedb-mark-on-light.svg` | the dog alone with a thin navy edge, on a light background (their light theme) |
| `chloedb-icon.svg`, `favicon-32.png`, `apple-touch-icon.png` | the dog on a rounded navy tile: favicons, app icons, anywhere under about 48 px |

The command center serves its own copies of the icon and the two marks
(`chloedb-server/ui/app/brand/`, compiled into the binary); change both
together.

Colours: navy `#1b212b`, red `#b62723` on light backgrounds and `#d8352f` on
dark ones (the website's text uses `#e5483f` on dark for contrast), white
`#f2f3f5`.
